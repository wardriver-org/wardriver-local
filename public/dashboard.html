    wardriver.org sync Optional · Off

    Selected imports can be contributed to wardriver.org. Uploads are always manual. The privacy engine below transforms the outbound copy only; your local SQLite database, maps, routes, photos, and exports remain exact and untouched.

    Sync is off. Local importing, mapping, routing, and exports continue to work normally.
    Outbound privacy boundary
    The transformation happens immediately before the wardriver.org request is built. Private-zone coordinates and the local pseudonym secret never leave this machine.

    WiGLE uploads are configured separately below and are not affected by these wardriver.org privacy settings.
    No uploads yet.

    Upload privacy

    Control exactly what the wardriver.org copy contains. Balanced is the default. Every control below affects wardriver.org uploads only.

    🛡 Moderate
    Balanced hides readable SSIDs, pseudonymizes device identifiers, snaps locations to 50 m, sends date-only time, waits at least 24 hours, and strips route/local metadata.

    Identifiers

    Prevent public network/device identifiers from being directly tied back to the exact local record.

    Location & time

    Location uses deterministic grid snapping, so repeated uploads cannot be averaged back toward the exact point.

    Metadata & categories

    Public attribution & photos

    Flock photos remain local-only in v2.18.0. These controls are saved now so photo sync cannot later bypass your chosen policy.

    Private upload zones

    Observations inside these zones are excluded before any identifier or location transformation. Zones never leave the local database.

    No private upload zones configured.
    Local-first guarantee: saving or changing these options never rewrites observations, BSSIDs, SSIDs, GPS coordinates, timestamps, photos, or route history in local SQLite. Only the wardriver.org request body is transformed.
    wardriver.org server policy target: ingest only the already-sanitized payload, avoid logging BSSIDs/tokens/request bodies, minimize IP retention, and support deletion of a contributor’s remote uploads. Those are server-side controls and are separate from this local client.

    WiGLE.net sync Optional · Off
    Optionally contribute a selected local import to WiGLE.net. Nothing uploads automatically. Wardriver converts the selected import to WiGLEWifi CSV and sends it only when you click Upload selected import.
    Sync only my data
    Download missing logs from your authenticated WiGLE upload history. Public network searches are never used. No deletions are synchronized.
    Manual sync · download only unless checked
    WiGLE upload is off. No data leaves this machine.
    How this works
    Authentication uses your WiGLE API token with HTTP Basic auth. Connection testing uses /api/v2/profile/user. Uploads use /api/v2/file/upload as WiGLEWifi CSV.

    Note: the current Wardriver local database does not retain RSSI, altitude, or accuracy fields after import, so exported WiGLE CSV uses neutral placeholders for those fields.
